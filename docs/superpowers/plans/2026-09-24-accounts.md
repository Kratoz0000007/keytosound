# Accounts (Plan 3b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every saved composition belongs to an email+password account. Anyone can play, but saving, the library and MIDI export need a login, and each user only ever sees their own compositions.

**Architecture:** The backend signs a 24h HS256 JWT with Nimbus (from `spring-security-oauth2-jose`) and puts it in an `HttpOnly`, `SameSite=Lax` cookie named `kts_session`. A stateless Spring Security chain turns that cookie into a principal (the user id), guards `/api/**`, and handles CORS with credentials. `CompositionService` takes the owner id on every call and scopes every query to it. The frontend adds a small auth client, a `useAuth` hook and an inline login panel. The save area depends on auth state, while typing and playback never do.

**Tech Stack:** Spring Boot 4.1.1, Java 22, Spring Security 7, Nimbus JOSE+JWT, Flyway, JPA, Zonky embedded PostgreSQL; React 19, TypeScript 5.8, Vitest 5.

**Spec:** `docs/superpowers/specs/2026-09-24-accounts-design.md`

## Global Constraints

- The backend stays a Java project: Spring Boot 4.1.1, Java 22, Jackson 3 (`tools.jackson.*`). Never add a dependency that brings in Jackson 2 (`com.fasterxml.jackson.databind`). jjwt and java-jwt are forbidden for that reason.
- New dependencies: only `spring-boot-starter-security`, `org.springframework.security:spring-security-oauth2-jose`, and `spring-boot-starter-security-test` (test scope). No resource-server starter.
- Cookie `kts_session`: `HttpOnly`, `SameSite=Lax`, `Path=/`, `Max-Age=86400`. `Secure` comes from `keytosound.auth.cookie-secure` (default `true`, `false` in dev). Logout sends it with `Max-Age=0`.
- JWT claims: `sub` = user id, `iss` = `keytosound`, `iat`, `exp` = `iat` + 24h. `keytosound.auth.secret` must be at least 32 bytes, or startup fails.
- Exact messages: `Log in to continue.`, `Email or password is incorrect.`, `An account with that email already exists.`, `password: must be at most 72 bytes`.
- Error body shape everywhere: `{ "error": …, "message": …, "at": … }`. Error codes: `not_found`, `invalid`, `conflict`, `unauthorized`.
- CORS allows only `http://localhost:5173` (drop `127.0.0.1`). Methods `GET, POST, DELETE`, header `Content-Type`, exposed `Content-Disposition`, credentials allowed.
- A composition owned by someone else is a **404, never a 403**.
- Git: every command is `git -c safe.directory=D:/projects/keytosound …`. Commit messages are very short, lowercase and unprefixed (no `feat:`/`fix:`), with **no `Co-Authored-By` trailer**. **Never push.** Never stage anything under `.claude/`.
- The UI stays on a **white background**, with no dark theme. Do not touch `frontend/src/engine/`: no notes are tied to any key except the digits.
- Frontend TypeScript: no constructor parameter properties (`erasableSyntaxOnly`, TS1294). `npx tsc -b` already reports TS1294 errors in files this plan does not touch, and those are expected. New code must add none.
- Shell: Windows. Use Git Bash for the commands below. In PowerShell 5.1 there is no `&&`, and `./mvnw` is `.\mvnw.cmd`.

## Rulings made while writing this plan

1. **Test users are inserted directly.** Spec §9 says the shared helper "registers a user". Here, `AuthTestSupport.createUser` inserts a `UserAccount` row and `sessionFor` mints its cookie. That keeps the composition and MIDI tests independent of the register endpoint, which `AuthControllerTest` covers on its own. Cost if wrong: swapping the helper body for a call to `/api/auth/register`.
2. **Component behaviour is tested as pure functions and then in the browser.** The repo has no DOM test environment: vitest runs `environment: 'node'`, with no jsdom and no Testing Library, and every existing UI test covers a pure module. So the spec §9 frontend bullets are tested through pure functions in Vitest (`saveAreaFor`, `isUnauthorized`, `authErrorMessage`, `checkSession`, `signOut`). The component wiring (401 → panel opens, recording kept, typing while logged out) is checked in the browser in Task 6. Cost if wrong: adding jsdom, `@testing-library/react` and Tone mocks later.
3. **A login password over 72 bytes gets 401, not 500.** Spring Security's bcrypt throws on input over 72 bytes, so login compares `""` instead and fails. The spec's "login applies no length check" is preserved as observable behaviour.
4. **`/error` is `permitAll`.** Otherwise Boot's error forward for an unhandled 500 hits the guard and reaches the browser as a 401, which the frontend would treat as "session expired".
5. **Tokens carry a `typ: JWT` header**, so any default type validator in Spring Security 7 accepts them.
6. **Test settings go in `src/test/resources/config/application.yml`**, not `src/test/resources/application.yml`. Boot loads `classpath:/config/` on top of `classpath:/`, whereas a test `application.yml` at the root would replace the main one entirely.
7. **The backend test files could not be read** while this plan was written. Tasks 1 and 2 therefore state the change to `CompositionControllerTest`, `MidiExportControllerTest`, `CompositionServiceTest` and `CompositionRepositoryTest` as exact mechanical rules rather than full file listings. Read each file before editing it.

```java
package com.keytosound.backend.auth;

import jakarta.servlet.http.Cookie;
import java.nio.charset.StandardCharsets;
import java.time.Instant;
import java.util.Base64;
import java.util.UUID;
import org.springframework.security.oauth2.jwt.JwtClaimsSet;
import org.springframework.security.oauth2.jwt.JwtEncoder;
import org.springframework.security.oauth2.jwt.JwtEncoderParameters;

/** Shared by every test that needs a logged-in caller or a deliberately bad token. */
public final class AuthTestSupport {

    private AuthTestSupport() {}

    /** A session cookie for userId, exactly as the login endpoint issues it. */
    public static Cookie sessionFor(TokenService tokens, UUID userId) {
        return new Cookie(AuthCookies.NAME, tokens.issue(userId));
    }

    /** A token with chosen claims, signed with the app's real key. */
    public static String token(
            JwtEncoder encoder, UUID userId, String issuer, Instant issuedAt, Instant expiresAt) {
        JwtClaimsSet claims = JwtClaimsSet.builder()
                .issuer(issuer)
                .subject(userId.toString())
                .issuedAt(issuedAt)
                .expiresAt(expiresAt)
                .build();
        return encoder.encode(JwtEncoderParameters.from(TokenService.HEADER, claims)).getTokenValue();
    }

    /** Swaps the payload for one naming another user, keeping the original signature. */
    public static String tampered(String token, UUID otherUser) {
        String[] parts = token.split("\\.");
        String payload = "{\"sub\":\"" + otherUser + "\",\"iss\":\"keytosound\",\"exp\":"
                + (Instant.now().getEpochSecond() + 3600) + "}";
        String forged = Base64.getUrlEncoder().withoutPadding()
                .encodeToString(payload.getBytes(StandardCharsets.UTF_8));
        return parts[0] + "." + forged + "." + parts[2];
    }
}
```

```java
package com.keytosound.backend.auth;

import static org.assertj.core.api.Assertions.assertThat;

import java.time.Duration;
import java.time.Instant;
import java.util.UUID;
import org.junit.jupiter.api.Test;
import org.springframework.security.oauth2.jwt.Jwt;
import org.springframework.security.oauth2.jwt.JwtClaimNames;
import org.springframework.security.oauth2.jwt.JwtDecoder;
import org.springframework.security.oauth2.jwt.JwtEncoder;

class TokenServiceTest {

    private final AuthProperties properties =
            new AuthProperties("unit-test-secret-0123456789abcdef", true);
    private final JwtConfig config = new JwtConfig();
    private final JwtEncoder encoder = config.jwtEncoder(properties);
    private final JwtDecoder decoder = config.jwtDecoder(properties);
    private final TokenService tokens = new TokenService(encoder, decoder);

    @Test
    void anIssuedTokenVerifiesToItsUser() {
        UUID user = UUID.randomUUID();
        assertThat(tokens.verify(tokens.issue(user))).contains(user);
    }

    @Test
    void theTokenNamesTheIssuerAndLasts24Hours() {
        Jwt jwt = decoder.decode(tokens.issue(UUID.randomUUID()));

        // getIssuer() would try to parse "keytosound" as a URL.
        assertThat(jwt.getClaimAsString(JwtClaimNames.ISS)).isEqualTo("keytosound");
        assertThat(Duration.between(jwt.getIssuedAt(), jwt.getExpiresAt())).isEqualTo(Duration.ofHours(24));
    }

    @Test
    void aTamperedPayloadIsRejected() {
        String token = tokens.issue(UUID.randomUUID());
        assertThat(tokens.verify(AuthTestSupport.tampered(token, UUID.randomUUID()))).isEmpty();
    }

    @Test
    void aTokenSignedWithAnotherSecretIsRejected() {
        AuthProperties other = new AuthProperties("another-secret-0123456789abcdef-xyz", true);
        TokenService foreign = new TokenService(config.jwtEncoder(other), config.jwtDecoder(other));

        assertThat(tokens.verify(foreign.issue(UUID.randomUUID()))).isEmpty();
    }

    @Test
    void anExpiredTokenIsRejected() {
        Instant now = Instant.now();
        String expired = AuthTestSupport.token(
                encoder, UUID.randomUUID(), "keytosound", now.minus(Duration.ofHours(25)), now.minus(Duration.ofHours(1)));

        assertThat(tokens.verify(expired)).isEmpty();
    }

    @Test
    void aTokenFromAnotherIssuerIsRejected() {
        Instant now = Instant.now();
        String foreign = AuthTestSupport.token(
                encoder, UUID.randomUUID(), "someone-else", now, now.plus(Duration.ofHours(1)));

        assertThat(tokens.verify(foreign)).isEmpty();
    }

    @Test
    void garbageIsRejected() {
        assertThat(tokens.verify("not-a-token")).isEmpty();
        assertThat(tokens.verify("")).isEmpty();
    }
}
```

```java
package com.keytosound.backend.auth;

import java.nio.charset.StandardCharsets;
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.boot.context.properties.bind.DefaultValue;

/**
 * Settings under {@code keytosound.auth}.
 *
 * @param secret the HS256 signing key. HS256 needs a 256-bit key, so anything
 *     under 32 bytes, or no secret at all, stops the app at startup rather
 *     than letting it sign sessions with a guessable key.
 * @param cookieSecure whether the session cookie is marked {@code Secure}. True
 *     unless a profile turns it off, as dev does for plain-http localhost.
 */
@ConfigurationProperties("keytosound.auth")
public record AuthProperties(String secret, @DefaultValue("true") boolean cookieSecure) {

    static final int MIN_SECRET_BYTES = 32;

    public AuthProperties {
        if (secret == null || secret.getBytes(StandardCharsets.UTF_8).length < MIN_SECRET_BYTES) {
            throw new IllegalStateException(
                    "keytosound.auth.secret must be set to at least " + MIN_SECRET_BYTES + " bytes");
        }
    }
}
```

```java
package com.keytosound.backend.auth;

import com.nimbusds.jose.jwk.source.ImmutableSecret;
import java.nio.charset.StandardCharsets;
import javax.crypto.SecretKey;
import javax.crypto.spec.SecretKeySpec;
import org.springframework.boot.context.properties.EnableConfigurationProperties;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.oauth2.jose.jws.MacAlgorithm;
import org.springframework.security.oauth2.jwt.JwtDecoder;
import org.springframework.security.oauth2.jwt.JwtEncoder;
import org.springframework.security.oauth2.jwt.JwtValidators;
import org.springframework.security.oauth2.jwt.NimbusJwtDecoder;
import org.springframework.security.oauth2.jwt.NimbusJwtEncoder;

/** Signs and checks session tokens with HS256 and the configured secret. */
@Configuration
@EnableConfigurationProperties(AuthProperties.class)
public class JwtConfig {

    @Bean
    public JwtEncoder jwtEncoder(AuthProperties properties) {
        return new NimbusJwtEncoder(new ImmutableSecret<>(key(properties)));
    }

    /** Checks the signature, the expiry (with Spring's default 60s skew) and the issuer. */
    @Bean
    public JwtDecoder jwtDecoder(AuthProperties properties) {
        NimbusJwtDecoder decoder = NimbusJwtDecoder.withSecretKey(key(properties))
                .macAlgorithm(MacAlgorithm.HS256)
                .build();
        decoder.setJwtValidator(JwtValidators.createDefaultWithIssuer(TokenService.ISSUER));
        return decoder;
    }

    private static SecretKey key(AuthProperties properties) {
        return new SecretKeySpec(properties.secret().getBytes(StandardCharsets.UTF_8), "HmacSHA256");
    }
}
```

`backend/src/main/java/com/keytosound/backend/auth/TokenService.java`:

```java
package com.keytosound.backend.auth;

import java.time.Duration;
import java.time.Instant;
import java.util.Optional;
import java.util.UUID;
import org.springframework.security.oauth2.jose.jws.MacAlgorithm;
import org.springframework.security.oauth2.jwt.JwsHeader;
import org.springframework.security.oauth2.jwt.JwtClaimsSet;
import org.springframework.security.oauth2.jwt.JwtDecoder;
import org.springframework.security.oauth2.jwt.JwtEncoder;
import org.springframework.security.oauth2.jwt.JwtEncoderParameters;
import org.springframework.security.oauth2.jwt.JwtException;
import org.springframework.stereotype.Component;

/** Issues and checks the session token. There is no refresh token: expiry means logging in again. */
@Component
public class TokenService {

    public static final String ISSUER = "keytosound";
    public static final Duration LIFETIME = Duration.ofHours(24);

    /** Without an explicit HS256 header the encoder would look for an RSA key. */
    static final JwsHeader HEADER = JwsHeader.with(MacAlgorithm.HS256).type("JWT").build();

    private final JwtEncoder encoder;
    private final JwtDecoder decoder;

    public TokenService(JwtEncoder encoder, JwtDecoder decoder) {
        this.encoder = encoder;
        this.decoder = decoder;
    }

    public String issue(UUID userId) {
        Instant now = Instant.now();
        JwtClaimsSet claims = JwtClaimsSet.builder()
                .issuer(ISSUER)
                .subject(userId.toString())
                .issuedAt(now)
                .expiresAt(now.plus(LIFETIME))
                .build();
        return encoder.encode(JwtEncoderParameters.from(HEADER, claims)).getTokenValue();
    }

    /** The user a token names, or empty when it is tampered, expired, foreign or not a token at all. */
    public Optional<UUID> verify(String token) {
        try {
            String subject = decoder.decode(token).getSubject();
            return subject == null ? Optional.empty() : Optional.of(UUID.fromString(subject));
        } catch (JwtException | IllegalArgumentException e) {
            return Optional.empty();
        }
    }
}
```

```java
package com.keytosound.backend.auth;

import java.time.Duration;
import org.springframework.http.ResponseCookie;
import org.springframework.stereotype.Component;

/**
 * The session cookie. HttpOnly so page JavaScript, including an injected
 * script, can never read the token. SameSite=Lax so a cross-site POST or
 * DELETE never carries it.
 */
@Component
public class AuthCookies {

    public static final String NAME = "kts_session";

    private final boolean secure;

    public AuthCookies(AuthProperties properties) {
        this.secure = properties.cookieSecure();
    }

    public ResponseCookie session(String token) {
        return base(token).maxAge(TokenService.LIFETIME).build();
    }

    /** Same attributes, so the browser matches and replaces the cookie; Max-Age=0 deletes it. */
    public ResponseCookie cleared() {
        return base("").maxAge(Duration.ZERO).build();
    }

    private ResponseCookie.ResponseCookieBuilder base(String value) {
        return ResponseCookie.from(NAME, value).httpOnly(true).secure(secure).sameSite("Lax").path("/");
    }
}
```

```java
package com.keytosound.backend.auth;

import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.Cookie;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.util.List;
import java.util.UUID;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.context.SecurityContext;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.web.filter.OncePerRequestFilter;
import org.springframework.web.util.WebUtils;

/**
 * Turns a valid session cookie into an authenticated request. A missing or
 * bad token leaves the request anonymous, and the endpoint's rule decides:
 * 401 on a protected endpoint, and nothing changes on a public one.
 *
 * <p>Deliberately not a {@code @Component}. Boot would also register a
 * component filter with the servlet container, where it would run outside the
 * security chain.
 */
public class JwtCookieAuthenticationFilter extends OncePerRequestFilter {

    private final TokenService tokens;

    public JwtCookieAuthenticationFilter(TokenService tokens) {
        this.tokens = tokens;
    }

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain chain)
            throws ServletException, IOException {
        Cookie cookie = WebUtils.getCookie(request, AuthCookies.NAME);
        if (cookie != null) {
            tokens.verify(cookie.getValue()).ifPresent(JwtCookieAuthenticationFilter::authenticate);
        }
        chain.doFilter(request, response);
    }

    private static void authenticate(UUID userId) {
        // The principal is the user id itself, so controllers take it as
        // @AuthenticationPrincipal UUID, and getName() is the id string.
        SecurityContext context = SecurityContextHolder.createEmptyContext();
        context.setAuthentication(UsernamePasswordAuthenticationToken.authenticated(userId, null, List.of()));
        SecurityContextHolder.setContext(context);
    }
}
```

```java
package com.keytosound.backend.config;

import com.keytosound.backend.auth.JwtCookieAuthenticationFilter;
import com.keytosound.backend.auth.TokenService;
import com.keytosound.backend.error.InvalidCredentialsException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.time.Instant;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.http.HttpMethod;
import org.springframework.http.MediaType;
import org.springframework.security.config.Customizer;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.annotation.web.configurers.AbstractHttpConfigurer;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.core.AuthenticationException;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.authentication.UsernamePasswordAuthenticationFilter;

/**
 * One stateless chain: no HTTP session, no JSESSIONID. The session cookie is
 * the only credential.
 *
 * <p>No CSRF token, because a forged request from another site is already
 * blocked twice. The SameSite=Lax cookie is not attached to a cross-site POST
 * or DELETE. And every mutating call sends Content-Type: application/json,
 * which forces a CORS preflight that fails for any origin outside the
 * allowlist. This holds only while the frontend and API share a site, i.e.
 * the same hostname (the browser ignores the port for this).
 */
@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain apiSecurity(HttpSecurity http, TokenService tokens) throws Exception {
        http.csrf(AbstractHttpConfigurer::disable)
                // Picks up the corsConfigurationSource bean from CorsConfig.
                .cors(Customizer.withDefaults())
                .formLogin(AbstractHttpConfigurer::disable)
                .httpBasic(AbstractHttpConfigurer::disable)
                .logout(AbstractHttpConfigurer::disable)
                .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
                .authorizeHttpRequests(auth -> auth
                        .requestMatchers(HttpMethod.POST, "/api/auth/register", "/api/auth/login", "/api/auth/logout")
                        .permitAll()
                        // Boot forwards unhandled failures here. Guarding it would
                        // turn a 500 into a 401, which the frontend reads as "session expired".
                        .requestMatchers("/error")
                        .permitAll()
                        .anyRequest()
                        .authenticated())
                .exceptionHandling(e -> e.authenticationEntryPoint(SecurityConfig::unauthorized))
                .addFilterBefore(new JwtCookieAuthenticationFilter(tokens), UsernamePasswordAuthenticationFilter.class);
        return http.build();
    }

    /** A 401 in the same {error, message, at} shape ApiExceptionHandler uses, never a redirect. */
    private static void unauthorized(
            HttpServletRequest request, HttpServletResponse response, AuthenticationException e) throws IOException {
        response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.setCharacterEncoding("UTF-8");
        response.getWriter().write("{\"error\":\"unauthorized\",\"message\":\"%s\",\"at\":\"%s\"}"
                .formatted(InvalidCredentialsException.NOT_LOGGED_IN, Instant.now()));
    }
}
```

```java
package com.keytosound.backend.config;

import java.util.List;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.cors.CorsConfiguration;
import org.springframework.web.cors.CorsConfigurationSource;
import org.springframework.web.cors.UrlBasedCorsConfigurationSource;

/**
 * The frontend is served by Vite on 5173 while the API runs on 8080, so the
 * browser treats every call as cross-origin. Spring Security applies this
 * (a WebMvcConfigurer mapping would be ignored by the security chain).
 *
 * <p>localhost only. 127.0.0.1 is a different site to the browser, so the
 * SameSite session cookie set by localhost:8080 would never reach it.
 */
@Configuration
public class CorsConfig {

    /** The bean name matters: http.cors(withDefaults()) looks it up by name. */
    @Bean
    public CorsConfigurationSource corsConfigurationSource() {
        CorsConfiguration config = new CorsConfiguration();
        config.setAllowedOrigins(List.of("http://localhost:5173"));
        config.setAllowedMethods(List.of("GET", "POST", "DELETE"));
        config.setAllowedHeaders(List.of("Content-Type"));
        // Without this the browser hides the header, and the download cannot
        // learn the file name the server chose.
        config.setExposedHeaders(List.of("Content-Disposition"));
        // The session cookie is a credential; without this the browser drops it.
        config.setAllowCredentials(true);

        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/api/**", config);
        return source;
    }
}
```

```sql
    id            UUID         PRIMARY KEY,
    email         VARCHAR(254) NOT NULL,
    -- 100, not bcrypt's 60: the hash carries its algorithm prefix
    -- ({bcrypt}$2a$10$...), which lets a later algorithm change happen

ALTER TABLE compositions ADD CONSTRAINT fk_compositions_user
```

```java
/** Every error leaves as {error, message, at}. */
@RestControllerAdvice
public class ApiExceptionHandler {

    @ExceptionHandler(NotFoundException.class)
    public ResponseEntity<Map<String, Object>> handleNotFound(NotFoundException e) {
        return body(HttpStatus.NOT_FOUND, "not_found", e.getMessage());
    }

    /** The first field error, as "field: message". */

    public ResponseEntity<Map<String, Object>> handleInvalid(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getFieldErrors().stream()
                .findFirst()
                .map(error -> error.getField() + ": " + error.getDefaultMessage())
                .orElse("The request is invalid.");
        return body(HttpStatus.BAD_REQUEST, "invalid", message);
```

```java
package com.keytosound.backend.auth;

import com.keytosound.backend.auth.dto.LoginRequest;
import com.keytosound.backend.auth.dto.RegisterRequest;
import com.keytosound.backend.auth.dto.UserView;
import com.keytosound.backend.error.ConflictException;
import com.keytosound.backend.error.InvalidCredentialsException;
import com.keytosound.backend.error.InvalidRequestException;
import java.nio.charset.StandardCharsets;
import java.util.Locale;
import java.util.Optional;
import java.util.UUID;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

/** Accounts. Free of web and cookie types; AuthController turns results into HTTP. */
@Service
public class AuthService {

    /** bcrypt ignores everything past 72 bytes, so a longer password is rejected rather than truncated. */
    static final int MAX_PASSWORD_BYTES = 72;

    private final UserAccountRepository users;
    private final PasswordEncoder passwords;
    /** Compared against when the email is unknown, so that path costs one bcrypt run too. */
    private final String dummyHash;

    public AuthService(UserAccountRepository users, PasswordEncoder passwords) {
        this.users = users;
        this.passwords = passwords;
        this.dummyHash = passwords.encode("timing-equaliser-not-a-real-password");
    }

    @Transactional
    public UserView register(RegisterRequest request) {
        if (!fitsBcrypt(request.password())) {
            throw new InvalidRequestException("password: must be at most " + MAX_PASSWORD_BYTES + " bytes");
        }
        String email = normalise(request.email());
        if (users.existsByEmail(email)) {
            throw new ConflictException("An account with that email already exists.");
        }
        return view(users.save(new UserAccount(email, passwords.encode(request.password()))));
    }

    /**
     * Exactly one bcrypt comparison on every path. Otherwise "no such email"
     * returns measurably faster than "wrong password" and reveals which emails
     * are registered.
     */
    @Transactional(readOnly = true)
    public UserView login(LoginRequest request) {
        Optional<UserAccount> user = users.findByEmail(normalise(request.email()));
        boolean fits = fitsBcrypt(request.password());
        // Spring's bcrypt throws on input over 72 bytes; such a password can never match anyway.
        boolean matches = passwords.matches(
                fits ? request.password() : "", user.map(UserAccount::getPasswordHash).orElse(dummyHash));
        if (user.isEmpty() || !fits || !matches) {
            throw InvalidCredentialsException.wrongEmailOrPassword();
        }
        return view(user.get());
    }

    /** A valid token for a deleted account is treated exactly like an expired one. */
    @Transactional(readOnly = true)
    public UserView me(UUID userId) {
        return users.findById(userId).map(AuthService::view).orElseThrow(InvalidCredentialsException::notLoggedIn);
    }

    static String normalise(String email) {
        return email.trim().toLowerCase(Locale.ROOT);
    }

    private static boolean fitsBcrypt(String password) {
        return password.getBytes(StandardCharsets.UTF_8).length <= MAX_PASSWORD_BYTES;
    }

    private static UserView view(UserAccount user) {
        return new UserView(user.getId(), user.getEmail());
    }
}
```

```java
 * user is still logged in.
 */
@RestController
@RequestMapping("/api/auth")
public class AuthController {

    private final AuthService auth;
    private final TokenService tokens;
    private final AuthCookies cookies;

    public AuthController(AuthService auth, TokenService tokens, AuthCookies cookies) {
        this.auth = auth;
        this.tokens = tokens;
        this.cookies = cookies;
    }

    /** Registering logs the new user straight in. */
    @PostMapping("/register")
    public ResponseEntity<UserView> register(@Valid @RequestBody RegisterRequest request) {
        UserView user = auth.register(request);
        return ResponseEntity.status(HttpStatus.CREATED)
                .header(HttpHeaders.SET_COOKIE, cookies.session(tokens.issue(user.id())).toString())
                .body(user);
    }

    @PostMapping("/login")
    public ResponseEntity<UserView> login(@Valid @RequestBody LoginRequest request) {
        UserView user = auth.login(request);
        return ResponseEntity.ok()
                .header(HttpHeaders.SET_COOKIE, cookies.session(tokens.issue(user.id())).toString())
                .body(user);
    }

    /** Clears this browser's cookie. A copied token stays valid until it expires (a known gap). */
    @PostMapping("/logout")
    public ResponseEntity<Void> logout() {
        return ResponseEntity.noContent()
                .header(HttpHeaders.SET_COOKIE, cookies.cleared().toString())
                .build();
    }

    @GetMapping("/me")
    public UserView me(@AuthenticationPrincipal UUID userId) {
        return auth.me(userId);
    }
}
```

```ts
import { useCallback, useEffect, useState } from 'react';
import { login, logout, me, register } from '../session/auth';
import type { User } from '../session/types';

export type AuthStatus = 'loading' | 'in' | 'out';

export interface AuthState {
  user: User | null;
  status: AuthStatus;
}

const LOADING: AuthState = { user: null, status: 'loading' };
const SIGNED_OUT: AuthState = { user: null, status: 'out' };

function signedIn(user: User): AuthState {
  return { user, status: 'in' };
}

/** 200 is in. A 401, or the backend being down, is out: playing never needs a login. */
export async function checkSession(): Promise<AuthState> {
  try {
    return signedIn(await me());
  } catch {
    return SIGNED_OUT;
  }
}

/** Always ends out locally, even if the request fails and the cookie outlives it. */
export async function signOut(): Promise<AuthState> {
  try {
    await logout();
  } catch {
    // Nothing to do: the local state still ends signed out.
  }
  return SIGNED_OUT;
}

export function useAuth() {
  const [state, setState] = useState<AuthState>(LOADING);

  useEffect(() => {
    let live = true;
    void checkSession().then((next) => {
      if (live) setState(next);
    });
    return () => {
      live = false;
    };
  }, []);

  // Failures propagate to the caller (AuthPanel shows them).
  const doLogin = useCallback(async (email: string, password: string) => {
    setState(signedIn(await login(email, password)));
  }, []);

  const doRegister = useCallback(async (email: string, password: string) => {
    setState(signedIn(await register(email, password)));
  }, []);

  const doLogout = useCallback(async () => {
    setState(await signOut());
  }, []);

  /** The server said 401: switch to out without another request. */
  const expire = useCallback(() => setState(SIGNED_OUT), []);

  return { ...state, login: doLogin, register: doRegister, logout: doLogout, expire };
}
```
